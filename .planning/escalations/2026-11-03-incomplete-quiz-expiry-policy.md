## What happened

시뮬레이터 보강 검증 준비 중 기존 `GET /api/v1/quiz/incomplete`가 시작한 지 24시간이 지난 미완료 퀴즈에 `completed_at`을 저장하는 정책을 확인했다. 모바일 홈이 이 API를 사용하므로 홈 진입도 세션 상태를 바꿀 수 있다. 이는 p6 활성화로 새로 만든 동작이 아니다.

기존 matching QA의 2/10 세션은 읽기 전용 확인 당시 약 92시간 경과해 자동 종료 대상이었다. 운영 기록 보존을 위해 그 계정으로 앱 홈을 열지 않았고, 최신 제품 코드와 같은 별도 합성 API·폐기형 DB의 전용 시뮬레이터로 재실행 검증을 분리했다. 운영의 세션 시각이나 완료 상태를 변경하지 않았다.

## Decision required

입문~N5 사용자가 다음날·며칠 뒤 미완료 퀴즈를 이어갈 수 있어야 하는지, 현재 시작 시각 기준 24시간 자동 종료 정책을 유지할지 결정한다. 정상 완료와 자동 종료의 의미를 계속 같은 필드로 표현할지도 검토 대상이다. API·DB 변경은 이번 검증 범위에서 적용하지 않는다.

## Options considered

1. 현행 24시간 정책을 유지하고 사용자에게 유효 기간과 종료 이유를 안내한다.
2. 시작 시각이 아니라 마지막 답안 저장 등 학습 활동을 기준으로 유예 기간을 정한다. 오래된 snapshot의 호환·만료 정책과 완료 통계 영향까지 먼저 설계한다.
3. 자동 종료 대신 사용자가 명시적으로 새로 시작하거나 정리하도록 한다. 보관 개수·콘텐츠 변경 시 복원 가능 여부와 오류 안내를 함께 설계한다.

## Recommended direction

현재 운영 동작은 유지하고 후속 정책 작업으로 분리한다. 학습 기록을 보존하면서 장기 이어하기의 기대와 맞는 유예 기간·사용자 안내·정상 완료와 종료 구분을 먼저 정한 뒤 구체 API/DB 안을 제시한다. 테스트 편의를 위해 기존 세션 시작 시각을 바꾸거나 만료 기록을 백필하지 않는다.

## Side effects

영향 범위는 홈 이어하기 카드, 일반·스마트·매칭·문장 배열의 세션 조회/재개, 세션 정리 및 완료 통계다. 기존 로그인·학습 기록·SRS/복습 기한·단어 목표·음원 캐시·Data API 차단은 그대로 유지한다.
