## Resolution

사용자가 상세안의 선택적 콘텐츠 보정과 서버 전환을 승인해 **결정 대기는 해소됐다**. 허용 범위는 81개 레슨의 대상 메타데이터 보완과 필요한 non-core 문법 링크 17개 추가, 검증한 서버 전환 및 전용 QA 확인이다. 기존 복습 이벤트·진도·점수·XP·연속일 교정은 계속 제외한다.

PR #184 병합·배포 후 새 리비전 `harukoto-api-00242-765`로 13:14:24 KST에 트래픽 100%를 전환했다. 기존 요청 해소 후 13:19:55 KST에 81개 레슨·405개 문항의 대상과 링크 17개를 반영했다. **운영 전용 QA의 로그인·레슨·이어 풀기 다섯 단계 45개 검사도 모두 통과해 운영 적용과 검증을 완료했다.** 기존 링크 548개, 기록 보존 검사 15개와 RLS·권한 지문이 같았고 QA 후에도 신규 QA 부분만 제외한 기존 범위가 최초 baseline과 완전히 같았다. Data API 비활성화와 익명·로그인 404를 확인했다. 자세한 결과와 한계는 [작업 기록](../../docs/operations/plans/lesson-review-target-fix-2026-10-21.md)에 구분한다.

## What happened

레슨 문항 순서로 SRS 대상을 추측하던 오류의 코드·콘텐츠 메타데이터·회귀 테스트를 준비했다. 운영은 읽기 전용으로 조사했으며 사용자는 DB나 기존 기록 변경 전에 구체적인 제안을 먼저 요청했다. 운영 콘텐츠에는 참조가 없어 새 서버만 먼저 배포하면 미보정 레슨 제출을 409로 거부한다.

## Decision requested before approval

[상세 적용안](../../docs/operations/plans/lesson-review-target-fix-2026-10-21.md)에 따라 81개 레슨·405개 문항에 400개 UUID 참조와 5개 명시 SRS 제외 사유를 추가하고 부족한 non-core 문법 링크 17개만 덧붙이는 운영 데이터 보정 및 서버 전환의 승인을 요청했고, 위 Resolution에서 승인으로 해결됐다. 기존 복습 이벤트·진도·점수·XP·연속일을 변경하는 것은 이 승인 범위에서 제외한다.

## Options considered

1. 기존 사용자 기록을 보존하고 콘텐츠 메타데이터 및 17개 링크만 보정한 뒤 검증된 서버로 전환한다. 짧은 전환 구간에 레슨 제출이 409로 거부될 수 있다.
2. 운영 적용을 보류한다. 코드 검증은 완료되어도 운영의 위치 기반 오기록 위험은 남는다.
3. 과거 이벤트를 추측으로 재배정하거나 상태를 초기화한다. 문항·답안·시도·콘텐츠 버전 증거가 없고 독립 퀴즈 학습도 섞여 있어 권고하지 않는다.

## Recommended direction

1번을 권고한다. 운영 READ ONLY 조사에서 레슨 복습 이벤트 94건·3개 계정·10개 레슨과 현재 대상 어휘 진도 62행을 확인했다. 현재 검토 대상과 다른 후보는 77건이지만 문항 순서를 역추정한 비교이며 확정된 과거 오류/정확한 복구 계획이 아니다. 과거 기록은 보존하고 미래의 대상 연결부터 정확히 고친다. 범용 시드의 링크 삭제·재생성은 사용하지 않는다.

## Side effects

- 기존 소개/SRS 등록은 `is_core` 필터가 없어 새 non-core 문법 17개도 포함된다.
- 동일 문법의 3개 문항에 SRS 3회 갱신하는 기존 정책은 유지했다. 한 레슨 내 중복 노출 집계는 별도 교육 설계 과제다.
- DB DDL·권한·RLS·Data API·환경변수 변경은 필요 없다. 이번 조사에서 해당 플랫폼/ACL 상태를 별도 재검증하지 않았으며 설정 변경도 하지 않았다.
- 적용 전 fingerprint·대상 UUID 검증과 보호된 사전 이미지, 원자적/멱등 보정, 새 서버 전환 후 로그인·학습·이어 풀기 확인이 필요하다. 상세안은 위 문서에 있다.
