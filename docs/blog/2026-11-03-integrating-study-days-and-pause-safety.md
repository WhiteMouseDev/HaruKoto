# 한 문제의 학습 기록을 인정하기 전에 통합 검증한 것들

한 문제라도 답하면 그날의 학습을 인정하도록 바꾸면서, 일일 목표·주간 그래프·연속일과 재시도 처리를 각각 구현했다. 개별 PR의 테스트가 통과했어도 이 코드가 함께 동작하는지는 별도로 확인해야 했다. 특히 기존 서버와 새 서버는 잠금 순서가 달라, 단순히 새 학습일 기능만 OFF로 배포하는 것으로 전환 안전성이 확보되지는 않았다.

이번에는 운영을 바꾸지 않는 통합 브랜치를 만들었다. 한 문항 인정과 주간 집계의 호환 코드, 완료 중복 방지와 계정별 목표, 기존 운영 코드용 저장 STOP을 합쳤다. 기존 PR과 현재 운영은 그대로 두었다. 새 스키마를 읽는 통합본을 실제 운영용 STOP 빌드로 잘못 사용하는 일도 피하도록 두 검증을 분리했다.

통합 충돌은 웹 답안 훅에서도 나타났다. 한쪽은 서버가 저장을 승인한 뒤 현재 계정의 통계를 갱신했고, 다른 쪽은 점검 중의 503 안내와 같은 답안 재시도를 추가했다. 한쪽을 선택해 다른 쪽을 버리면 저장되지 않은 답안이 출석으로 표시되거나 점검 안내가 사라질 수 있었다. 공통 훅의 계정 경계와 ACK 이후 갱신을 유지하면서 STOP 안내를 함께 처리하고, 거절된 답안이 출석 캐시를 갱신하지 않는 회귀를 추가했다.

기존 웹 테스트 실패 7개도 다시 살폈다. 실제 제품 코드에 가나 업적이 세 개 추가됐는데 개수20을 기대하거나, 누적 통계로 바뀐 화면에 사용하지 않는 today 값을 전달하는 오래된 테스트였다. 제품 동작을 테스트에 맞춰 되돌리지 않고 현재 계약을 검사하도록 갱신했다. 서로 다른 일별 분모에서 누적 정답률을 단순 평균하지 않는지, 단어와 문법의 문항 수가 다를 때 숙련도를 올바르게 가중하는지, N1 완료 뒤 존재하지 않는 다음 단계를 안내하지 않는지도 추가했다.

폐기형 PostgreSQL에서는 새 학습일 마커와 활동 영수증을 실제로 넣고 STOP 전후를 비교했다. 차단 시에는 인증·사용자 잠금·DB 처리에 들어가지 않아야 하고, 해제 후 같은 활동/제출 ID를 재시도하면 기록이 한 번만 반영돼야 했다. 기존 기록·복습 기한·목표·음원·ACL/RLS·Data API 차단도 함께 보존되는지 확인했다. 기존 스키마 검증의 버전 문자열만 새 값으로 바꾼 결과를 통합 검증으로 사용하지 않았다.

여기까지의 소스는 기본 OFF이며 운영 적용 기록이 아니다. 운영은 카탈로그와 배포 메타데이터만 읽었다. 현재 주소의 연결과 프로젝트의 production 포인터가 다를 수 있어 실제 alias를 기준으로 전환 대상을 정해야 한다는 점도 확인했다. STOP이 기존 실행을 취소하거나 예전 웹 탭을 바꾸는 것은 아니므로, 이후에는 이전 배포 경로 차단·실행 종료 증거·복구 가능한 OFF 빌드를 함께 준비해야 한다.

[통합 검증·기존 실패 분류·운영 준비 기록](../operations/plans/study-day-integration-qa-2026-11-03.md)에 결과와 한계를 구분해 남겼다. 복구를 위해 학습 기록을 지우거나 Data API를 다시 여는 방식은 사용하지 않는다.

원격 CI에서는 새 모바일 테스트 네 개가 로컬 빌드 설정에 의존한 점도 발견했다. 실제 HTTP 클라이언트는 기존 compile-time API 주소가 필요한데 CI 테스트 명령에는 없었다. 앱 생성자를 바꾸거나 테스트를 건너뛰지 않고, 테스트 실행에 비밀 없는 `.invalid` 합성 주소를 명시했다. 환경파일 없이 전체1,068개를 다시 통과시켰고 실제 요청은 모두 테스트 adapter에서 처리했다. 로컬 성공과 재현 가능한 CI 성공도 별개라는 사례였다.

운영 준비에는 코드 밖의 미확정 사항도 남았다. 현재 없는 WAF 설정을 처음 게시한 뒤 완전히 원래 상태로 되돌리는 절차와 기존 handler의 실제 종료를 아직 입증하지 못했다. 코드가 통과했다고 이를 완료로 기록하지 않았다. [운영 변경 요청 명세](../operations/plans/study-day-operating-change-proposal-2026-11-03.md)에 대상·영향·복구안과 진행하지 않을 조건을 남기고 실제 적용은 별도 단계로 유지했다.
