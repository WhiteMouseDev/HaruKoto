# 저장하지 못했다는 응답을 오답으로 바꾸지 않기

가나를 처음 배우는 사람에게 정답 표시는 학습의 기준이다. 실제로는 통신이 실패했는데 오답이라고 알려주면, 사용자는 방금 익힌 문자와 소리의 연결부터 의심할 수 있다. 하루코토의 레슨 결과 피드백을 개선한 뒤 가나의 두 활성 학습 화면을 검토하면서 이 경계를 다시 확인했다.

가나 시작 API는 정답 노출을 막기 위해 정답 ID를 응답에서 제외한다. 정오는 답안 저장 응답에서 받는다. 그런데 기존 화면은 요청 오류를 무시한 뒤 기본 로컬 false를 답안 목록에 넣고 타이머로 다음 문제에 갔다. 완료 요청도 실패를 알린 뒤 단계 완료를 기다리지 않고 성공 화면으로 진행할 수 있었다. 서버가 완료의 중복 반영을 막는 것과 클라이언트가 실제 저장을 확인하는 것은 서로 다른 문제였다.

이번 수정은 서버의 정오·점수·보상 정책을 바꾸는 대신 화면의 진행 조건을 바꾼다. 선택했다고 곧바로 답안을 확정하지 않고 서버가 저장을 확인한 뒤 피드백과 다음 문제를 연다. 실패한 경우에는 같은 문제·선택·세션을 유지해 같은 요청을 다시 보낼 수 있게 한다. 퀴즈 완료 뒤 단계 저장만 실패했다면 이미 성공한 퀴즈 완료까지 반복하지 않는다.

기존 재전송 계약의 한계도 확인했다. 현재 신규 가나 세션의 같은 답안은 원래 판정을 재생하지만, 완료 재전송의 XP0은 추가 보상이 없다는 의미다. 최초 보상도0이었다고 표시하면 안 된다. 시작 요청에는 멱등 키가 없으므로 응답이 유실된 시작을 같은 세션으로 복구한다고 약속하지 않는다. 필요한 범위를 기존 계약으로 구현하고, 서버의 단계 완료와 퀴즈 성공을 연결하는 정책은 별도 제안으로 남긴다.

같은 가나 영역이어도 문자카드의 진도 저장은 계약이 달랐다. 같은 문자 ID를 다시 보내면 학습 횟수와 일별 집계가 한 번 더 늘었다. 여기에 다른 재시도 버튼을 그대로 복제하면 성공 응답을 잃어버린 학습을 중복 집계할 수 있다. 이 경로는 오류 안내와 계정 보호까지만 보완하고 재전송은 추가하지 않았다. 새 행동 ID와 기존 비공개 영수증을 사용하는 [별도 API·제약 확장안](../operations/plans/kana-card-progress-retry-contract-proposal-2026-11-04.md)을 먼저 제시하고, 승인 전에는 서버나 기존 기록을 바꾸지 않는 것으로 범위를 나눴다.

계정 경계는 버튼에서 한 번 확인하는 것으로 끝나지 않는다. 늦게 도착한 답안과 타이머가 새 계정의 화면을 진행시키지 않도록 요청 전후와 화면 종료를 함께 처리한다. 정상적인 로그인과 세션 저장 방식을 유지하면서 재시도 요청이 다른 계정에 반영되지 않는지도 교차 검토한다.

이 작업과 함께 N5 첫 챕터의 전문 검수 자료를 만들었다. 원문·보기·정답·해설을 모아 보기 쉽게 만든 것과 일본어 교육 전문가가 승인한 것은 다르다. 기존 AI 보조 APPROVED를 사람의 PASS로 복사하지 않고, 콘텐츠와 실제 음원 판정을 각각 PENDING으로 남겼다. 새 검수표가 기존 전체 N5 음성 대상을 덮어쓰지 않게 파일 발견 규칙도 분리했다.

히라가나·가타카나 쓰기 연습은 구현 전 설계로 구분했다. 획순을 보고 따라 쓴 다음 가이드를 가리고 떠올리는 흐름을 제안하되, 그 활동을 기존 퀴즈의 가짜 정답이나 단계 완료로 보내 학습일을 만들지 않는다. 필기 인식의 confidence와 교육용 정답 점수도 구분한다. 먼저 작은 자산 묶음과 실제 손가락 입력으로 사용성을 확인하고, 서버 학습일 인정은 별도 계약으로 다루는 방향이다.

최종 구현·회귀·합성 네이티브 검증 결과와 적용 경계는 [가나 저장 개선 기록](../operations/plans/kana-save-retry-and-qa-2026-11-04.md), 전문가에게 넘길 자료는 [첫 챕터 검수 원장](../operations/qa/n5-ch01-expert-review-2026-11-04.md), 후속 기능은 [쓰기 연습 설계](../operations/plans/kana-handwriting-practice-design-2026-11-04.md)에 구분해 남긴다. 운영 적용은 검증 결과를 먼저 보고한 뒤 별도 승인 범위로 둔다.
