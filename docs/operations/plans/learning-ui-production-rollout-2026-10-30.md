## 서버 보존과 실제 API 확인

배포 전·후·smoke 후에 읽기 전용으로 비교했다. 환경·Secret 바인딩·서비스 계정·이미지 이외의 런타임 설정이 동일하며, Kenzo·Shizuka 역할 Secret 버전 1도 유지됐다. 전역 gcloud 기본 계정을 바꾸지 않고 기존 프로젝트용 계정을 명시했다. 값·토큰·비밀번호는 문서나 저장소로 복사하지 않았다.

- 기존 N5 대화 음원 198행·문제 음원 250행, 총 **448행 변경·삭제·추가 0**.
- N5 콘텐츠 50개와 권한/RLS 보안 카탈로그 지문 동일.
- 제한된 기존 QA 계정의 user 1·daily progress 1·lesson progress 1·quiz sessions 8·answers 14 지문 동일. 모든 운영 사용자의 기록을 전수 조회한 결과로 확대하지 않는다.
- 정상 로그인·profile·dashboard·history·N5 chapters·HN5-004 detail·읽기 전용 quiz resume 모두 **HTTP 200**.

- HN5-004 대표 음원 4개의 TTS URL·MP3 SHA·전체 디코딩이 배포 전후 동일. 전체 448개 파일 청취를 수행한 것은 아니다.

- 새 리비전의 배포 이후 ERROR 로그를 최대 20개 조회한 결과 0개.

정상 비밀번호 로그인 2회는 인증 세션을 생성하는 동작이다. 학습 답안·완료 제출이나 기존 데이터 보정은 하지 않았으며, 인증 저장까지 포함해 쓰기 0회로 표현하지 않는다. 정리 쓰기가 있을 수 있는 `/quiz/incomplete`는 검증에서 제외했다.

## 아이폰 빌드와 설치 보존

새 바이너리는 정확한 병합 main `9c8b2cb6`에서 Flutter 3.41.3으로 빌드했다. 전체 추적 모바일 파일 674개를 Git archive와 비교해 일치했고, 기존 환경 파일 지문과 AOT의 필수 설정도 확인했다. 이전 673개 manifest에서 제외한 추적 `.env.example` 한 개까지 포함해 검사한 수치이며 다른 추가·누락 파일은 없다.

새 작업트리에 ignored plugin registrant가 없어 첫 빌드는 중단됐다. 기존 lockfile의 offline/enforce-lockfile 생성으로 등록 파일을 복구한 뒤 같은 소스로 재빌드해 통과했다. CocoaPods가 바꾼 tool-version footer 한 줄만 원본과 대조해 복원했고 작업트리는 깨끗했다. iPhoneOS arm64, min iOS 15, strict/deep codesign, 유효한 device provisioning, 기존 앱 ID·서명 팀·키체인·Apple 로그인 권한의 완전 일치를 검증했다.

사용자 잠금 해제 직후 단일 Preferences plist만 private 0600으로 복사해 비교했다. 전체 container나 keychain을 추출하지 않았다. 업데이트 직전·직후, 앱 실행 전에 **기존 체크포인트 2개·설정·같은 계정 identity 지문·Preferences 파일 전체 지문이 동일**했다. 토큰·평문 계정 ID는 출력하지 않았다. 실제 새 앱의 홈에서도 로그인 유지와 연속 학습 카드를 확인했다.

앱 실행·달력 조회 후에도 체크포인트·설정·동일 계정 지문은 유지됐다. 정상 앱의 인증 갱신이 있어 Preferences 파일 전체 지문은 달라질 수 있으므로 설치 전후의 완전 동일 검사와 구분한다. 실제 아이폰 계정의 기존 세션을 비공개로 소비해 profile/dashboard/현재 월 history GET만 조회했고 모두 200이었다. 세션과 API profile의 계정 지문이 같고, 현재·최장 연속일·오늘 학습 여부·월별 체크 수가 실제 화면과 일치했다. 별도 로그인·refresh·logout·기록 쓰기는 하지 않았다.
