# N5 화자 음성 A/B 샘플 실행 기록

상태: 실제 여덟 파일 생성·파일 검사 완료, 사용자 선호·일본어 정확성 판정 PENDING. 운영 적용은 하지 않았다.

## 입력과 범위

현재 공개 HN5-004 ‘공통점이 반가울 때’ 네 줄의 원문·alias를 그대로 사용했다. 남성 후보는 Kenzo - Calm, Soft and Measured, 여성 후보는 Kaori – Relatable and Friendly Voice다. 제공업체 카탈로그에서 일본어·두 모델 지원, 기본 요율 1.0, notice 조건을 확인했다. 이름형 화자의 성별·나이·관계를 새로 확정한 것이 아니다.

A는 eleven_multilingual_v2, B는 eleven_v4이며 같은 두 voice를 사용한다. 모델별 지원 설정을 분리했다. 사용자에게 두 후보·모델·최대 여덟 파일·총 114자 범위를 제시한 뒤 승인된 작업 범위에서 실행했다. 글로벌·운영 env 설정은 바꾸지 않고 단일 프로세스 안에서 실제 voice와 모델 override를 사용했다. 자격 증명 값은 메모리에서만 사용하고 파일·채팅·Git에 기록하지 않았다.

카탈로그/모델/사용 한도의 GET과 유료 생성의 POST를 구분했다. 먼저 인증 없는 카탈로그 GET 두 번은 401로 끝났고 원시 응답은 내보내지 않았다. 기존 HaruKoto 자격 증명을 이용한 읽기 전용 GET 다섯 번에서 두 모델 접근과 후보·한도를 확인했다. 계정 음성 추가·설정 변경·새 자격 증명 생성은 하지 않았다. 샘플 job은 TTS POST 정확히 여덟 번과 완료 뒤 사용량 GET 한 번만 수행했다. 별도 재생성이나 자동 재시도는 없다.

## 사용자 검수 자료

로컬 산출물: `build/n5-speaker-review-2026-10-26/`. index.html, 원본 MP3 여덟 개, 단일줄 네 개를 로컬 연결한 A/B 미리듣기 두 개, 민감 정보 없는 summary와 ZIP이 있다. build 산출물은 Git에 커밋하지 않는다. 작업 트리를 정리할 때 필요한 검수 ZIP은 먼저 별도 보존해야 한다.

비교 화면은 처음 모델명을 가리고, 네 문장 이어듣기와 같은 문장끼리 A/B 재생을 제공한다. 한 음성을 시작하면 다른 플레이어를 정지한다. 화면과 미디어 길이·컨트롤 표시를 브라우저에서 확인했다. 실제 청취·문장 발음·모델 선호는 아직 판정하지 않았다.

확인할 것은 두 화자의 구분, 일관성, 따라 하기 편한 명료도·속도, 장음·촉음·조사 등 읽기, 누락·추가·잘림·과한 감정이다. 기존 앱의 사용자 기능 PASS를 새 샘플 전체 승인으로 이월하지 않는다. 선호를 확인한 뒤 네 행 운영 적용안을 별도로 제시한다.
