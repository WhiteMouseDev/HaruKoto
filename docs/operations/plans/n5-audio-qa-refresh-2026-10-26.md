# N5 음성 검수 도구·현재 목록 갱신

## 승인과 범위

사용자는 PR #195 병합, PR #162 충돌 정리, 현재 N5 음성 검수 목록과 직접 들어볼 대표 레슨·확인 항목 준비를 승인했다. PR #195는 2026년 10월 26일 15:44:00 KST에 `5bfabe4b5202553698c15c5cc0b24d396b72a28f`로 병합했다. 원본의 미커밋 작업을 보존하고 기존 관리 작업 트리의 `codex/n5-audio-qa-refresh`에서 기존 PR #162 head와 현재 main을 병합한다. PR #162 자체의 병합·운영 배포는 이번 승인에 포함하지 않는다.

API·DB·권한·Data API·기존 학습 기록·복습 기한·환경 계약·생산 의존성은 변경하지 않는다. 필요하면 구체적인 안을 먼저 제시한다. TTS 생성·재생성·seed 적용·STT 모델 호출·검수 판정 적용은 수행하지 않는다.

## 구현 계획

1. 충돌한 검수 보고 스크립트와 회귀에서 기존 N4 챕터 검색·판정 의미와 N5 level 선택을 함께 유지한다. 새 날짜의 N5 챕터 packet을 추가할 때 과거 파일이 중복 합산되거나 예전 PASS가 새 PENDING을 가리지 않도록 회귀를 둔다.
2. 기존 공식 CA·검증된 TLS와 REPEATABLE READ·READ ONLY, 시간·행 수 제한을 사용한 새 기준선으로 기존 학습 기록·보안 지문을 비교한다. 과거 임시 기준선이 없어 사흘간 기록 불변을 주장하지 않는다. 개인 행·자격 증명·서명 URL을 공개 자료로 내보내지 않는다.
3. 현재 공개 N5 레슨·대화·문제와 저장 TTS를 batch SELECT로 가져와 같은 스냅샷에서 대조한다. 공개 콘텐츠와 공개 GCS URL만 private 작업 자료로 저장한다. runtime 입력과 cached text의 정확 일치·누락·중복·source order를 구분한다.
4. 같은 snapshot을 기반으로 현재 날짜의 챕터별 packet·index·정합 보고서를 만든다. 5월 자료는 과거 기록으로 보존한다. 기존 판정을 현재 음성·문장에 검증 없이 이월하거나 자동 PASS로 만들지 않는다.
5. 가능한 범위의 공개 음성 URL·파일·길이·무음 검사는 DB 접속 없이 snapshot으로 수행한다. machine 검사, STT 실행 여부, 사람 판정, 실제 앱 UAT를 각각 구분한다.
6. 대표 레슨 HN5-004 ‘공통점이 반가울 때’의 대화 네 줄과 기초 대안 HN5-001 ‘처음 만난 자리’를 직접 들을 수 있는 짧은 확인표를 준비한다. 실제 운영 연결과 현재 텍스트를 확인한 URL만 제공한다. 단어 TTS는 별도 경로, question TTS는 현재 모바일 UI 미연결, 전체 듣기는 reading.audioUrl이 있을 때만이라는 범위를 명시한다.

## 검증과 완료 기준

영향 범위 회귀부터 실행하고 API의 기존 검증·호환 경계를 확인한다. N4 기존 packet 검색·명시적 packet 선택·waiver/invalid 의미가 보존돼야 한다. 새 검수 자료는 source·audio·판정의 일치와 현재 날짜를 제시하며 개인 데이터·비밀정보를 포함하지 않아야 한다. 독립 검토와 문서 포맷·비밀정보 검사를 수행하고 PR #162 설명을 최종 범위·검증·남은 사람 검수로 갱신한다.

대표 레슨의 앱 체험은 시범 사용 근거다. 한 챕터 대표 검수와 전체 N5의 미판정 항목 해소를 자동 대체하지 않는다. 오디오 언어 품질이나 광범위 공개 승인을 machine PASS로 주장하지 않는다.

## 롤백

검수 도구·문서 변경을 revert한다. 운영 DB·기록·권한·오디오를 수정하지 않으므로 데이터 보정이나 DB rollback은 필요하지 않다. 실제 실행 결과와 제한은 아래에 기록한다.

## 실행 결과 — 2026년 10월 26일

- PR #195는 위 main commit으로 병합했다. PR #162의 두 충돌 파일을 해결했고, 추가 변경은 검수 스크립트·회귀 테스트·관련 문서로 제한했다. HTTP API·운영 앱 코드·스키마·권한·환경 계약·의존성은 수정하지 않았다.
- N4 기본 검색 경로 7개와 전체 보고서 필드가 현재 main과 정확히 같다. 양쪽 모두 279개 대상 중 PASS 234·PENDING 45이며, 이는 N4 전체 검수 완료를 뜻하지 않는다.

- 현재 공개 N5는 50레슨·9챕터·대화 198개·문제 안내 250개다. runtime 원문·strip·저장 text는 448/448 일치하고 누락·중복·고아·서명 URL은 없다.

## 운영 보존 확인과 해석 한계

- 공개 N5 레슨 50개·챕터 9개·허용 TTS metadata 448개의 canonical SHA는 모두 동일하다. 텍스트 448/448 일치도 유지된다.
