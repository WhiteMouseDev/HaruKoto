# 가나 기본 46자 추천과 쓰기 이어하기

## 범위

- 히라가나·가타카나 각각 기본 46자의 행별 연습 순서를 안내한다.
- 최근 일반 쓰기 연습 한 개를 계정·문자 종류별로 기기에 저장한다.
- 행/묶음, 글자, 단계(획순 보기·가리고 쓰기·단어에서 찾기)를 복원한다.
- 저장한 손글씨와 예시 공개·단어 선택 상태도 같은 글자에 한해 복원한다.
- 기존 166자 자유 선택, Klee One 본보기, 헷갈림 표시 및 날짜별 복습을 보존한다.

API, DB, 로그인, 서버 출석·학습률·XP·단어 목표·복습 기한과 Data API 설정은 변경하지 않는다. 새 의존성은 추가하지 않는다. 쓰기 완료 표시는 기기에 저장한 연습 완료이며 숙련도 판정이 아니다.

## 추천과 완료 기준

- 기본 행 순서에서 아직 연습을 완료하지 않은 첫 행을 추천한다. 어느 행이든 자유롭게 선택할 수 있다.
- 일반 행 연습을 마지막 글자까지 진행해 마쳤을 때 해당 기본 행을 완료한다. 기존의 쓰기 건너뛰기는 유지한다.
- 비교 묶음·헷갈림 복습으로 기본 행을 완료한 것으로 추정하지 않는다.
- 과거 연습 완료 정보가 없으므로 기존 복습 표시로 완료 기록을 백필하지 않는다.
- 모든 기본 행을 마친 후에는 전체 완료를 안내하고 자유 재연습을 제공한다.

## 저장과 복원

- 별도 버전의 로컬 키를 사용하고 계정과 문자 종류로 분리한다. 기존 복습 키는 수정하거나 이관하지 않는다.
- 안정적인 글자 ID로 세션을 저장한다. 배열 위치만으로 글자를 식별하지 않는다.
- 화면 전환과 완료는 저장 성공 후 반영한다. 저장 실패는 현재 화면에서 알리고 같은 의도를 재시도한다.
- 그리기는 획이 끝날 때 저장하고, 미완성 포인터 입력은 저장하지 않는다. 좌표는 정규화하며 기존 획/좌표 개수 상한을 따른다.
- 다시 열 때 선택 화면의 이어하기 카드에서 재개한다. 다른 행으로 바꾸는 경우 저장 위치 교체를 명확하게 안내한다.
- 손상된 데이터나 알 수 없는 버전을 만났을 때 조용히 새 데이터로 덮어쓰지 않는다.
- 계정 전환·오래된 비동기 응답이 다른 계정의 표시나 저장에 영향을 주지 않도록 소유권을 검사한다.
- 다음 날 새 단어 복습은 기존 날짜별 완료 방식으로 유지한다. 일반 쓰기 이어하기와 별도로 동작한다.

## 검증 계획

1. 모델/저장소: 기본 46자 순서와 완료, 166자 ID, 잘못된 데이터, 저장 실패·재시도, 중복 입력, 계정·문자 분리.
2. 위젯: 획순·쓰기·단어 단계에서 닫았다 열기, 새 컨테이너 복원, 손글씨·공개 상태·선택 상태, 다음 행 추천과 자유 선택.
3. 기존 가나·전체 모바일 회귀 테스트, formatter와 analyzer.
4. 전용 iOS 시뮬레이터에서 실제 앱 프로세스 종료·재실행 후 같은 글자/단계와 기기 복습 표시 복원. 합성 로그인·fixture를 사용하며 운영 데이터에는 접근하지 않는다.

## 적용 및 롤백

- 이 작업은 구현·로컬/시뮬레이터 검증 범위이다. 운영 배포와 실기기 설치는 포함하지 않는다.
- 앱 코드를 되돌리면 새 쓰기 진도 키를 읽지 않게 된다. 기존 복습 키 및 서버 데이터는 그대로 유지된다.
- 새 로컬 키는 롤백 시 삭제하지 않아 재적용 후에도 복원할 수 있도록 한다.

### 검증 도구 보완

- 새 프로세스의 Flutter 디버그 컴파일 서비스가 준비되기 전에 평가하던 자동화를 재연결 대기 방식으로 보완했다.
- 예시 단어 `カラオケ`의 オ 위치에 맞게 UI 조작의 목표 인덱스를 수정했다.
- CFPreferences의 물리 plist 반영이 개별 저장 ACK보다 늦을 수 있어, 합성 복습을 심은 직후의 부분 파일을 기준으로 삼지 않고 최초 ACK 확인 값과 저장 완료 후 파일을 대조했다. 이후 안정된 네이티브 지문으로 종료·재실행 전후를 다시 비교했다. 제품 코드 변경은 필요하지 않았다.
