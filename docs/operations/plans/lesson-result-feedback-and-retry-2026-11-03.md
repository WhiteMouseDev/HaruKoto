# 레슨 결과 피드백·오답 보기·조회 재시도 개선

2026-11-03 KST. 사용자가 결과의 정답·완성 문장·해설, 오답 우선 보기, 복습 안내 및 레슨 조회 재시도 개선과 회귀·시뮬레이터 검증을 승인했다. 운영 적용 전 결과를 보고하며, API·DB 변경이 필요하면 구체안을 먼저 확인한다. 기준 main은 PR #227까지 병합된 `48715838`이다.

## 구현 범위

1. 결과의 서버 `isCorrect` 판정을 유지한다. `order`가 유일하게 일치하는 문제에서만 정답 보기 ID를 원문으로 바꾸고, 배열 정답은 `correctOrder`의 토큰과 중복을 보존해 완성 문장으로 표시한다. 누락·중복·알 수 없는 ID에 다른 문제나 임의 정답을 대입하지 않는다.
2. 오답이 있으면 ‘오답만’ 보기를 기본으로 하고 ‘전체’로 전환한다. 각 보기 안의 기존 문항 순서를 유지하며 원본 결과·점수·답안은 변경하지 않는다. 전부 정답·문항 없음·결과 재빌드도 다룬다.
3. 기존 결과 해설과 학습자용 복습 문구를 표시한다. `nextReviewAt`은 제출 당시의 문항별 일정 스냅샷이므로 ‘제출 당시 복습 예정’으로 한국 시간의 절대 시각을 표시한다. 현재의 복습 기한으로 오해시키거나 음수 상대 시간을 표시하지 않는다. 현재 일정은 학습 탭에서 확인하도록 안내한다.
4. 학습 탭의 레슨 조회 실패는 해당 영역에서 재시도한다. 조회 중·실패·성공한 빈 목록을 구분하고, 복습·가나 영역은 계속 사용한다. 계정·레벨 전환과 늦은 응답, 재시도 연타를 기존 Riverpod·계정 가드 패턴으로 다룬다.

## 보존과 계약 경계

- 기존 API에 정답 ID·정답 배열·해설·일정이 있어 계약·DB 변경 없이 모바일에서 구현한다. 백엔드 담당자가 각 필드의 의미를 읽기 전용으로 확인했다.
- 과거 제출 결과 복구는 기존 요약 전용 화면을 유지한다. 과거 결과에는 옛 질문·보기 전체가 없으므로 변경된 최신 콘텐츠와 자동 결합하지 않는다.
- 보기 전환·결과 읽기·조회 재시도는 레슨 시작·답안·제출·XP·SRS 갱신을 수행하지 않는다. 기존 명시적 ‘다시 풀기’ 동작과 결과가 불명확한 제출 재시도는 바꾸지 않는다.
- 로그인·학습 기록·복습 기한·오늘 단어 목표·음원·Data API·권한·클라우드 설정은 변경 대상이 아니다. 새 의존성·환경 계약·플랫폼 설정도 추가하지 않는다.

합성 검증 안전 보고서 SHA256은 `17e766764e75f447e3c9a7761df2f293027764352418cdfb98a18c19e3c77c06`다. 전용 합성 앱과 시뮬레이터만 종료했으며 기존 계정 앱은 홈에서 실행 중이다. API·DB·기존 학습 기록·복습 기한·오늘 목표·Data API 설정을 바꾸는 후속 작업은 이 적용에 포함되지 않는다.
