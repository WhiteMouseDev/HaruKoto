## 직접 확인할 대표 레슨

[사용자용 5~10분 듣기 확인표](n5-representative-listening-check-2026-10-26.md)에서 ‘공통점이 반가울 때’의 대화 네 줄을 먼저 듣는다. 기초 대안은 ‘처음 만난 자리’다. 두 레슨의 여덟 파일은 현재 텍스트 일치·HTTP 200·machine PASS·경고 0이다. 문장별 정식 언어 판정은 아직 비어 있다. 이후 사용자는 기본 재생 네 항목의 정상 동작과 두 화자가 같은 여성 목소리로 들리는 문제를 보고했다. 확인한 레슨·문장 범위는 미지정이므로 448개 정식 판정을 변경하지 않았다. [화자별 음성 수정안](n5-dialogue-speaker-voices-2026-10-26.md)을 참고한다.

단어 카드 음성은 별도 어휘 TTS다. 문제 안내 250개는 현재 모바일 레슨 문제 UI에 재생 버튼이 연결돼 있지 않아 이 packet의 직접 링크로 검수한다. 10월 26일 앱은 `reading.audioUrl`이 있어야 전체 듣기를 표시했다. PR #197 이후에는 기존 문장 음원을 순서대로 재생하므로 이 URL 없이도 전체 듣기를 사용할 수 있다. 현재 확인은 위 10월 28일 자료를 따른다.

## 판정과 적용 경계

대표 레슨 네 줄 체험은 시범 사용 근거다. 기존 기준의 최소 대표 검수는 한 챕터 전체이며, 전체 N5 공개 판단에는 남은 대상의 검수 상태와 별도 결정을 함께 확인해야 한다. 모든 현재 packet은 새 PENDING으로 만들었으며 과거 PASS를 이월하지 않았다.

N5 기본 검색은 챕터별 최신 날짜 파일만 선택한다. 5월 기록은 보존하며 `--packet`으로 명시해 볼 수 있다. 같은 챕터·날짜의 모호한 중복이나 잘못된 날짜는 차단한다. N4 기존 검색·판정 의미는 유지한다.

```bash
cd apps/api
uv run python scripts/report_n4_audio_qa_verdicts.py --level N5 --json --fail-on-blocker
```

현재 예상 결과는 448 PENDING에 따른 차단이다. 이는 검수 완료를 주장하지 않도록 하는 정상 게이트다. 기존 `apply_n4_audio_qa_verdicts.py`는 HN4 heading만 지원하므로 N5에 그대로 적용하지 않는다. 이번 작업은 확인표 준비·보고이며 판정 적용·DB 수정·음성 재생성을 실행하지 않았다.
