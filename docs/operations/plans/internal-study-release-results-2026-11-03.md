# 한 문항 학습일 인정 내부 전환 기록 — 2026-11-03

이 문서는 정식 출시 전 여러 내부 테스터가 공유 DB를 사용하는 환경의 전환 기록이다. 사용자 승인으로 전원 사용을 중단한 뒤 적용했다. Preview/WAF 격리는 이번 전환 범위에서 제외했다. 기존 기록을 지우거나 과거 출석을 소급 인정하지 않았다.

## 문제가 생긴 이유와 설계

완료 시점에만 집계하는 구현 때문에 한 문항을 풀고 중단한 사용자는 실제로 학습했어도 연속일과 주간 통계에서 학습하지 않은 것처럼 보였다. 또한 완료 요청을 재전송하거나 저장 실패 뒤 다시 시도할 때 성공 UI와 실제 저장이 엇갈리거나 중복 반영될 가능성이 있었다. 계정이 바뀌었는데 이전 계정의 목표가 남는 문제도 함께 다뤘다.

학습일 인정, 오늘 단어 목표, XP와 복습 기한을 각각 다른 의미로 구분했다. 실제 저장된 첫 답안은 정오와 무관하게 그 KST 날짜의 학습 활동으로 인정한다. 오늘 단어 목표와 주간 단어 수는 KST 일별 고유 단어 답안을 기준으로 하고, XP·숙련도·복습 기한은 기존 정책을 유지한다. 단순 화면 열기나 음원 재생은 답안 저장과 같게 취급하지 않는다.

레슨의 문항 응답에는 계정·시도·활동 ID와 콘텐츠 버전을 연결한다. 같은 활동 ID의 재시도는 기존 접수 결과를 돌려주고, 응답 유실 후에는 조회로 복구한다. 일별 마커와 비공개 receipt를 같은 트랜잭션 안에서 처리해 첫 저장과 학습일이 어긋나지 않게 했다. 완료 저장 보호와 계정별 목표는 활성화 전에 호환 버전으로 먼저 배포한다.
