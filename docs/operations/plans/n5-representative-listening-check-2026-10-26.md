# N5 대표 레슨 듣기 확인표

작성일: 2026년 10월 26일. **문장·파일 검사 완료. 사용자는 기본 재생 네 항목의 정상 동작을 보고했으며, 화자 목소리가 같아 어색하다는 문제를 제기했다.** 문장별 정식 언어 검수는 대기다. 사용자 보고의 범위는 아래에 따로 기록한다.

## 5~10분 동안 확인할 것

이번에는 일본어 발음을 전문적으로 채점하기보다 화면과 소리가 맞고, 앱에서 편하게 다시 들을 수 있는지 확인한다. 기본 표본은 **‘공통점이 반가울 때’의 대화 네 줄**이다. 더 익숙한 내용이 필요하면 아래의 ‘처음 만난 자리’를 대신 사용한다. 두 레슨을 모두 해야 하는 과제는 아니다.

앱에서 **학습 → N5 → 1번 역 → 4번째 레슨 ‘공통점이 반가울 때’ → 대화 말풍선의 스피커**를 누른다. 1번 역 이름은 ‘인사와 첫 만남’이다. 기본 대안은 같은 역의 1번째 레슨 ‘처음 만난 자리’다.

‘전체 듣기’는 전체 대화 `audioUrl`이 연결돼 버튼이 표시될 때만 확인한다. 버튼이 없으면 그 항목의 판정을 비워 두고 메모에 ‘버튼 없음’으로 적는다. 단어 카드 스피커는 별도 어휘 TTS이므로 이 대화 음성의 검수와 구분한다. 현재 모바일의 문법 카드·문제에는 별도 TTS 버튼이 없어 이번 확인 대상에 넣지 않는다.

## 확인 순서와 기능 판정표

문장 스피커로 네 줄을 한 번씩 들은 뒤 아래 동작을 해본다. **현재 재생 중 버튼을 한 번 누르면 정지하고 다시 누르면 대상 문장을 재생하는 동작**을 기준으로 정지·다시 듣기가 되는지 확인한다. ‘한 번 더 눌러야 해서 어색하다’ 같은 사용감은 기능 실패와 구분해 의견 칸에 남긴다.

판정은 직접 확인한 항목에만 `PASS` / `FLAG` / `FAIL` 중 하나를 적는다. `PASS`는 확인한 범위에서 문제를 느끼지 못함, `FLAG`는 확신이 없거나 추가 확인·사용감 검토 필요, `FAIL`은 무음·다른 문장·잘림·멈추지 않음·동시 재생처럼 재현되는 문제다. 안 들었거나 실행하지 않은 항목은 빈칸으로 둔다.

| 확인 항목                   | 해볼 동작                                                             | 판정 | 문장 번호·증상·의견                     |
| --------------------------- | --------------------------------------------------------------------- | ---- | --------------------------------------- |
| 화면과 소리 대응            | 각 말풍선의 문장과 실제로 들리는 내용이 대응하는지 확인               | PASS | 사용자 직접 보고; 레슨·문장·기기 미지정 |
| 처음과 끝의 잘림            | 문장 앞부분·끝부분이 갑자기 끊기거나 무음인지 확인                    | PASS | 사용자 직접 보고; 레슨·문장·기기 미지정 |
| 정지·다시 듣기              | 재생 중 누르기 → 정지 확인 → 다시 누르기                              | PASS | 사용자 직접 보고; 레슨·문장·기기 미지정 |
| 화면 이동 뒤 겹침           | 재생 중 화면을 나갔다 돌아와 한 문장을 다시 듣고 소리가 겹치는지 확인 | PASS | 사용자 직접 보고; 레슨·문장·기기 미지정 |
| 듣기 편한 속도              | 네 줄을 들으며 따라가기 너무 빠르거나 어색하게 느린지 의견 기록       | PASS | 사용자 직접 보고; 레슨·문장·기기 미지정 |
| 전체 듣기(버튼이 있을 때만) | 전체 대화를 한 번 재생하고 순서·잘림·겹침 확인                        |      |                                         |

일본어 읽기, 장음·촉음과 억양의 정확성은 숙련 검수자가 별도로 판단한다. 익숙하지 않거나 확신이 없으면 ‘정확함’으로 승인하지 말고 `FLAG`와 ‘확인 필요’를 남긴다. 이번의 편한 속도 평가를 일본어 정확성 판정으로 바꾸지 않는다.

## 짧게 보내주실 응답

- 확인한 레슨명: `(직접 입력)`
- 해당 문장 번호 또는 화면 문장: `(직접 입력)`
- 기기·재생 상황(예: 휴대폰 스피커 / 이어폰 / 화면을 나갔다 돌아옴): `(직접 입력)`
- 판정(`PASS` / `FLAG` / `FAIL`): `(직접 입력)`
- 증상 또는 사용감 한 줄: `(직접 입력)`

기기 고유 번호나 계정 정보는 적지 않아도 된다. 문제가 있는 문장만 위 양식으로 알려주면 된다. 직접 확인한 네 줄의 체험은 **1차 표본 확인**이며 대표 챕터 전체의 정식 검수 gate나 N5 전체 음성 승인을 완료한 것으로 처리하지 않는다.

## 사용자 직접 확인 — 2026년 10월 26일

사용자는 앞서 안내한 네 항목(문장 대응·앞뒤 잘림, 정지·다시 듣기, 화면 이동 뒤 겹침, 따라가기 편한 속도)이 정상이라고 직접 보고했다. 첫 항목을 두 행으로 나눈 위 표의 기능 다섯 행을 사용자 보고 PASS로 기록한다. 레슨명·개별 문장 번호·기기·스피커/이어폰은 이번 메시지에 명시되지 않아 추정하지 않는다. Codex의 새 캡처·직접 청취·기기 조작 결과가 아니다.

**화자 목소리 구분: FLAG.** 사용자는 두 인물이 동일한 여성 목소리로 들려 대화가 어색하다고 보고했다. 정상 재생과 대화의 화자 구분 품질은 서로 다른 확인이다. 기존 448개 음성의 문장별 정식 verdict를 PASS로 바꾸지 않는다.

콘텐츠에는 김의 남성 alias와 다나카의 여성 alias가 이미 있으나 서버 생성 경로에서 사용하지 않는 것을 소스로 확인했다. 성씨만으로 성별을 새로 정하지 않는다. [화자별 음성 수정안](n5-dialogue-speaker-voices-2026-10-26.md)에 원인·설정·표본 교체 범위를 기록했다. 운영 음성과 설정은 아직 바꾸지 않았다.
