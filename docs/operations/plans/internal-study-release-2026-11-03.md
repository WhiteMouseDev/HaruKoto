# 내부 테스트용 학습 기능 반영 준비

## 이번 요청과 범위

2026-11-03 사용자는 정식 출시 전 내부 테스트 단계이므로 Preview 격리 인프라보다 검증된 기능의 내부 반영을 우선하도록 요청했다. 다른 내부 테스터도 있다고 확인했다. 이번에는 **배포가 일어나지 않는 작업 브랜치로 검증 코드를 정리하고, 내부 전환 리허설·앱 빌드 준비와 구체적인 DB 적용/복구안을 마련**한다. main 병합·실제 DB/권한/클라우드 변경·서버 배포·기기 설치는 아직 실행하지 않는다.

기존 학습 기록·로그인·복습 기한·오늘 단어 목표·음원 및 Kenzo/Shizuka 설정·Data API 차단을 유지한다. 기존 승인안 외 새 DDL/API/runtime env 계약을 추가하지 않는다. 적용 전에 변경 내용을 제시하라는 이전 사용자 요청을 유지한다.

Preview와운영이같은DB설정항목을공유한다는사실은남는다. 별도인프라를지금만들지않되공유DB의Preview에서로그인/학습검증을하지않고, 이번검증은localhost폐기형DB·합성계정·별도QA앱으로제한한다. 내부테스터의실제접속경로에Preview가있다면그경로도전환중사용중지대상에포함해야한다.

## 소스 정리

통합 OFF #219는 #215·#217·#218 코드를 포함하고 CI868이 성공했다. #219를 #215 작업 브랜치에 merge해 `72f01bea`가 됐고, 그 tree가 검증된 `b61f6600`와 같음을 확인했다. #217도 head가 포함돼 merged 상태로 정리됐다. **main 대상 #215는 아직 draft·미병합**이다. 문서 #220도 작업브랜치 기준으로 갱신하고, #216은 최종OFF를 포함한 활성화draft로 유지하며 운영활성화로 표현하지 않는다.

## 간단한 내부 전환안: 아직 실행하지 않음

1. 모든 내부 테스터에게 알려진 앱·웹 테스트를 잠시 멈추도록 요청하고 확인한다. 임의로 타인에게 메시지를 보내지 않으며 테스트 중단 확인 전에는 DB작업을 하지 않는다. 접속 범위를 확신할 수 없으면 먼저 범위를 확인한다.
2. 현재 main/배포·DB head와 원본 복구 artifact·비밀값을 노출하지 않는 설정 snapshot을 확인한다. 전환 중 예기치 않은 자동 배포/alias 변경을 통제하는 구체안도 승인받는다. 변경할 설정만 보존하고 전체 설정을 덮어쓰지 않는다.
3. 실제 사용하는 API/웹에 호환되는 임시 학습 저장중지와 알려진 접속경로의 신규 쓰기 중지를 확인한다. 현재 진행 요청·트랜잭션/잠금과 내부사용중지확인을함께대조한다. 로컬리허설성공을실제서버종료증거로쓰지않는다. 504/고정대기만으로종료를단정하지않는다.
4. 실제DB가검토한o5이고전환조건이충족된경우에만기존p6마이그레이션을적용한다. activity_recorded기본false와비공개activity receipt를추가하며과거출석백필은하지않는다. lock2초/statement15초·원자적실패롤백을유지한다.
5. #217을포함한새스키마호환OFF 서버/웹을반영하고로그인·기존학습·음성·기한·목표·이어하기를확인한다. 테스트가끝나기전에는여러테스터의동시학습을재개하지않는다.
6. 확인된ON코드로인정을활성화하고내부테스트를재개한다. 첫레슨답안/단어답안·재시도·앱재실행·계정별목표·주간그래프·다음날연속일을점검한다. 자동배포설정은검토한기준으로복구한다.

기존 writer와 새 writer는 잠금 순서가 다르므로 짧은 테스트 중단도 없이 섞어 배포하지 않는다. 다만 내부 테스터/실사용 경로를 확인할 수 있으면 새 WAF나 전체 Preview 격리 구축을 필수로 요구하지 않는다. 실제 중단시간은 실행 정리와 검증에 따라 달라지며 고정 분 수나 무중단을 약속하지 않는다.

## 실제 DB 승인 전 제시할 내용

- 정확한 마이그레이션 revision·신규 컬럼/테이블·기존행 보존·실패시 원자적 rollback 및 사용후 downgrade 금지 조건.
- 실제사용중인서버/웹 artifact·임시중지/재개와필요한최소설정변경·원복목록.
- 로컬전환리허설 결과, 앱빌드/서명·저장형식 유지 확인, 남아있는실행/기기확인범위.
- 다른내부테스터의짧은테스트중단확인. Preview인프라와WAF변경은포함하지않는다.

## 롤백

p6 전에는 같은 구스키마/잠금의 기존 artifact로 복구한다. p6/새 writer 도입 후에는 #217 포함 새 schema 호환 OFF로 새인정만중지한다. marker·receipt·학습기록삭제나Data API개방을복구수단으로쓰지않는다. 앱을삭제하거나로그아웃/저장키삭제로진행위치를정리하지않는다.
