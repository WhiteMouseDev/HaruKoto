# 한 단어 저장 직후 주간 통계 반영안·구현 기록

> 상태: 2026-11-02 사용자가 선택적 필드와 즉시 반영을 승인했다. 구현·회귀·격리 시뮬레이터 검증을 완료했고 운영에는 적용하지 않았다. 최종 결과와 보존 롤백은 [통합 구현 기록](answered-study-day-policy-implementation-2026-11-02.md)을 따른다.

## 추가로 전달된 문제

사용자가 전달한 11월 2일 디자이너 피드백은 홈의 ‘오늘 단어 1개만 학습해도 그래프가 채워져요’ 안내와 실제 완료 묶음 기준 통계의 불일치다. 한 문항 학습일 마커만으로는 단어 막대 수치까지 바뀌지 않는다.

변경 전 모바일 `weekly_chart.dart`는 `weeklyStats[].wordsStudied` 합이 0이면 학습 여부/XP와 무관하게 ‘이번 주 학습 기록이 아직 없어요’를 표시한다. 서버의 wordsStudied는 일별 완료 집계이며 단어·한자·듣기 퀴즈 완료의 정답 수를 반영한다. 따라서 부분 학습·오답 한 문항·문법/가나/레슨 학습은 기록이 있어도 비어 보일 수 있다.

## 승인한 추가 API 변경

FastAPI 대시보드와 웹 BFF의 주간 항목에 아래 선택 필드를 추가했다.

```text
weeklyStats[].vocabularyAnsweredCount?: integer >= 0 | null
```

- 정의는 오늘 단어 목표와 같은 **KST 하루 동안 저장한 고유 단어 답안 수**다. 사용자 소유 세션의 quiz_type과 답안 question_type이 모두 VOCABULARY인 행에서 question_id를 날짜별 중복 제거한다. 정답·오답 모두 포함한다.
- 기존 wordsStudied·xpEarned는 보존한다. 기존 완료 시 집계·XP·SRS·복습 기한·오늘 단어 목표 계산은 수정하지 않는다. DB 구조나 기록을 UPDATE할 필요도 없다.
- 기간 안의 단일 GROUP BY 조회를 사용하고 날짜마다 일곱 번 조회하지 않는다. 기존 epoch 기반 UTC-naive/aware 호환과 KST 경계를 따른다.
- 모바일/API의 최근 7일, 웹의 월~일이라는 기존 기간 차이는 그대로 둔다. 기간 정책 변경을 섞지 않는다.
- 표시하는 주간 합계는 **일별 고유 단어 수의 합**이다. 같은 단어를 서로 다른 두 날짜에 공부하면 두 번 포함되며 주간 전체의 고유 단어 수라고 설명하지 않는다.

## UI와 호환성

새 필드가 있으면 단어 막대·단어 합계·목표선에 사용한다. 구 응답의 누락/null은 확정 0이 아니며 기존 wordsStudied로 호환 표시하고 완료 기준임을 구분한다. 기존 API 필드를 삭제하거나 의미를 덮어쓰지 않는다.

문법·가나·레슨만 학습해 단어 수와 XP가 0인 날도 hasStudied로 학습 표시를 남긴다. ‘기록 없음’ 판정을 단어 수 0만으로 하지 않는다. 학습 여부 점/테두리와 단어 수 막대는 구분하며 단어 수를 꾸며 높이지 않는다. 저장 성공 뒤 대시보드 갱신은 진행 중인 한 문항 정책의 ACK 경계를 사용한다.

이 조회는 기존에 저장한 최근 답안도 읽으므로 **과거 주간 막대가 이전 완료/정답 집계와 달라질 수 있다.** 원본 행·출석 마커·연속일을 보정하는 백필은 아니지만 표시 기준 변화다. 과거 출석을 새로 인정했다고 설명하지 않는다.

## 승인 범위와 검증

추가로 필요한 것은 선택적 API 투영·OpenAPI/생성 타입·모바일/웹 모델과 주간 카드다. 회귀는 한 단어 오답 저장 후 미완료 상태의 1개 표시, 같은 단어/같은 날 중복 제외, 다른 날 학습 포함, 문법/가나/레슨만 학습한 날 표시, 저장 실패·구 응답 호환·KST/주 경계·새로고침/재실행을 포함한다. 기존 기록·기한·XP·목표·음원·Data API는 보존한다.

실제 PostgreSQL 8개 시나리오에서 API와 정확한 웹 SQL 결과가 일치했다. 모바일 신규 회귀 10개, 웹 신규 회귀 8개를 포함한 최종 검사를 통과했다. 별도 시뮬레이터에서 정식 단어 퀴즈 첫 오답만 저장하고 1/8에서 종료했을 때, 오늘 목표 1/20·5%와 주간 단어 1개·XP 0이 표시됐다. 앱 완전 재실행 뒤에도 2/8로 이어지고 기존 세션·답안 1개·학습 상태 해시가 같았다. 운영 적용은 한 문항 정책과 함께 별도 승인이 필요하다.
