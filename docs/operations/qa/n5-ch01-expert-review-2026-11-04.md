## 사용 순서와 판정 기준

1. 일본어 교육 경험과 한국어 학습자 설명 능력을 갖춘 검수자가 원문·읽기·번역·난이도·정답의 유일성을 검토한다. 원어민이라는 이유나 디자이너 선호만으로 교육 품질 판정을 대신하지 않는다.
2. 5레슨의 목표 제안과 실제 문법·대화·전체25문항이 대응하는지 먼저 본다. 보기 선택·배열 성공만으로 실제 말하기 능력이 검증됐다고 판정하지 않는다.
3. 아래의 원문은 수정하지 않고, 마지막 콘텐츠 판정 원장에 검수자·일시·근거·수정안을 적는다. JSON 동반 파일은 원문과 동일 ID/판정 필드를 제공한다. Markdown과 JSON 중 사용할 편집 원장을 하나 정하고 최종 확정 시 서로 대조한다.
4. 음성은 별도 원장이다. 먼저 실제 앱의 현재 연결 URL·전체 SHA-256·원문·화자를 확인한다. 연결 확인이 안 된 항목은 BLOCKED 또는 PENDING으로 남긴다. 구 음원의 PASS를 새 파일로 이월하지 않는다.
5. 수정 제안은 콘텐츠 행·음원 객체·캐시 연결과 기존 값 보관/롤백안을 별도로 정리한다. 이 문서에 PASS를 적어도 운영에 자동 적용되거나 새 음원이 생성되지 않는다.

## 먼저 확인할 검수 질문

- HN5-001: 부제목은 `です/だ`를 예고하지만 문법·대화·문항은 `です` 중심이다. 목표를 좁힐지 내용을 보완할지 판정한다. 현재 문구를 자동으로 고치지 않았다.
- HN5-001-Q05·HN5-002-Q05·HN5-003: `私は`·`は`를 주어와 화제/주제로 설명하는 방식이 섞여 있다. 한국어 입문자에게 전달할 용어·설명 수준을 일관되게 정한다.
- HN5-002~003 대화: `来ました`·`分かります`·`楽しい` 등 목표 밖 표현을 맥락으로 허용할지, 읽기/뜻/선행 학습 안내가 필요한지 본다. 등장 자체를 오류로 단정하지 않는다.
- 다섯 레슨이 각각 단어 선택2·빈칸 선택2·배열1로 구성된다. 목표 표현을 보기 없이 자기 정보로 바꾸어 말하거나 써보는 관찰이 추가로 필요한지 검토한다. 현재 앱 평가 문항을 바꾸지는 않는다.
- 성씨로 화자 성별을 추정하지 않는다. `voice_id`는 소스의 역할 alias이며 실제 캐시의 목소리·모델 확인과 구분한다. Kenzo/Shizuka 채택은 기존 캐시 전체 교체나 전체 발음 승인이 아니다.

## HN5-001 · 처음 만난 자리

- 소스 부제목: です/だ로 기본 자기소개하기
- 주제: 자기소개 · 소스 예상 시간: 10분 · 챕터 순서: 1
- **검수용 목표 제안 `HN5-001-CD01`**: 처음 만난 사람에게 인사하고 자신의 이름과 신분을 짧게 말할 수 있다. (기존 승인 콘텐츠 아님)
- 목표 관찰 제안: 정답 보기를 가린 뒤 자신의 이름·신분·관심사 등으로 핵심 문장을 바꿀 수 있는지 확인한다. 실제 검사는 아직 하지 않았다.

### HN5-001-G01 · 문법 원문과 참조 자료

- 레슨 문법: `〜です` / ~입니다 / ~이에요
- 연결: grammar order `1` · 원문 참조 표기 `L1` (외부 자료의 최신 내용/허가를 검증한 것이 아님)
- 기존 문법 데이터 뜻: ~입니다 / ~이에요
- 기존 문법 데이터 해설: 명사나 형용사 뒤에 붙여서 정중하게 말하는 기본적인 표현입니다. 일본어에서 가장 기본이 되는 서술 표현으로, 상대방에게 예의를 갖추어 사실이나 상태를 전달할 때 사용합니다. 한국어의 '~입니다', '~이에요'에 해당합니다.

## HN5-002 · 어디서 오셨나요?

- 소스 부제목: か로 기본 질문하기
- 주제: 질문 · 소스 예상 시간: 10분 · 챕터 순서: 2
- **검수용 목표 제안 `HN5-002-CD01`**: 상대가 유학생인지 정중하게 묻고, 자신에 대한 간단한 질문에 대답할 수 있다. (기존 승인 콘텐츠 아님)
- 목표 관찰 제안: 정답 보기를 가린 뒤 자신의 이름·신분·관심사 등으로 핵심 문장을 바꿀 수 있는지 확인한다. 실제 검사는 아직 하지 않았다.

### HN5-002-G01 · 문법 원문과 참조 자료

- 레슨 문법: `〜か` / ~인가요? / ~입니까?
- 연결: grammar order `31` · 원문 참조 표기 `L1` (외부 자료의 최신 내용/허가를 검증한 것이 아님)
- 기존 문법 데이터 뜻: ~인가요? / ~입니까? (의문 조사)
- 기존 문법 데이터 해설: 문장 끝에 か를 붙이면 질문(의문문)이 됩니다. 정중체에서는 'です/ます + か'의 형태로 사용하며, 억양을 올릴 필요 없이 か만으로 질문을 나타낼 수 있습니다. 한국어의 '~인가요?', '~합니까?'에 해당합니다.
